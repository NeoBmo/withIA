# Configuración

Copias de mi configuración global de Claude Code, tal como la uso. Son un punto
de partida: **adáptalas** antes de copiarlas.

| Archivo | Va en | Qué hay que cambiar |
|---|---|---|
| [CLAUDE.md](CLAUDE.md) | `~/.claude/CLAUDE.md` | La sección "Quién soy", tu idioma, tu terminal y tus herramientas |
| [settings.json](settings.json) | `~/.claude/settings.json` | Las rutas de los hooks (apuntan a mi usuario de Windows) |
| [hooks/](hooks/) | `~/.claude/hooks/` | Nada; necesitan Node.js |

Cómo encajan las piezas: [practices/guardrails.md](../practices/guardrails.md).

> Estas copias no se sincronizan solas: si cambio mi configuración, actualizo
> este repo a mano.
